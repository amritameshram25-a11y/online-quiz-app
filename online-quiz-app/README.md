# Quizly — The Developer Quiz

A responsive, client-side quiz built with React and Vite. Challenge yourself with
10 multiple-choice questions about HTML, CSS, JavaScript, and React, with a
15-minute countdown, saved answers, progress tracking, and an automatic score.

## Run locally

```sh
npm install
npm run dev
```

## Validate and build

```sh
npm run lint
npm run build
```

## Project structure

- `src/data/questions.js` contains the quiz questions and correct answers.
- `src/components/` contains the reusable brand and welcome, quiz, and result screens.
- `src/App.jsx` manages the quiz state, timer, navigation, and score.
